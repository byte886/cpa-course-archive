本文档定义CPA备考知识库的各级节点内容规范、标题命名规则、父节点内容生成原则，确保知识库结构统一、风格一致、便于导航和使用。

## 节点标题命名规范

### 1. 课程节点（第三级）

**格式**：`【XX考季】VIPCPA系列-XX科目（XX老师）`

**示例**：
- `【26考季】VIPCPA系列-税法（蔡俊峻老师）`
- `【26考季】VIPCPA系列-会计（罗翔老师）`

**规则**：
- 考季用两位数字表示（如26代表2026年）
- 科目名称用标准考试科目名（税法、会计、审计、财务成本管理、公司战略与风险管理、经济法）
- 老师姓名用括号标注

### 2. 章节节点（第四级）

**格式**：`XX章节名称`（XX为两位数字序号）

**示例**：
- `01税法总论`
- `02增值税法`
- `03消费税法`

**规则**：
- 序号从01开始，两位数字
- 章节名称与课程大纲一致
- 不添加空格或其他分隔符

### 3. 内容节点（第五级）

**固定名称**：
- `知识拆解` — 核心知识点整理（定义、分类、原则、表格）
- `考试指导` — 考点分析、做题技巧、易错点提醒、记忆口诀

**规则**：
- 每个章节下固定包含这两个子节点
- 名称统一，不随章节变化

## 父节点内容生成原则

### 核心原则

1. **AI自主决定**：遇到新节点时，由AI根据节点层级和子节点情况自主决定是否生成内容，无需询问用户
2. **有子节点必有内容**：如果节点有子节点，必须生成包含子节点链接的目录内容
3. **子节点更新同步父节点**：当子节点内容更新后，父节点的概述、重点内容等也需要同步更新
4. **统一模板**：所有同级节点使用相同的内容模板

## 父节点内容同步机制

### 触发条件

当子节点内容发生以下变化时，需要同步更新父节点：

1. **新增子节点**：父节点的目录列表需要添加新子节点链接
2. **子节点内容重大更新**：父节点的章节概述、重点内容需要更新
3. **子节点状态变化**：父节点的状态表格需要更新（如"待开始"→"进行中"→"已完成"）

### 同步流程

1. 更新子节点内容
2. 检查父节点是否需要同步更新
3. 更新父节点的目录、概述、重点内容、状态等
4. 更新父节点的"更新记录"
5. 验证父节点内容与子节点一致

## 节点内容生成决策树

遇到新节点时，按以下流程决定是否生成内容：

```
新节点创建
    │
    ├─ 是否有子节点？
    │   ├─ 是 → 必须生成内容（包含子节点目录链接）
    │   └─ 否 → 继续判断
    │
    ├─ 是否为内容节点（知识拆解/考试指导）？
    │   ├─ 是 → 必须生成内容（核心内容）
    │   └─ 否 → 继续判断
    │
    ├─ 是否为根节点或课程库节点？
    │   ├─ 是 → 必须生成内容（导航和说明）
    │   └─ 否 → 可以暂时为空，等有子节点后再生成
```

## 文档维护

- 本文档由AI维护，遇到新情况或发现规范不合理时及时更新
- 更新时记录变更原因和日期
- 所有知识库节点的生成和更新都必须遵循本文档规范
