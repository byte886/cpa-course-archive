## 题目与解析

### 第1题（单选题）
**题目**：纳税人将金银首饰与其他非金银首饰组成成套消费品销售的，计算征收消费税的依据是？
- A. 组成计税价格
- B. 金银首饰的销售额
- C. 金银首饰与其他非金银首饰的销售额合计 ✓
- D. 其他非金银首饰的销售额

**解析**：金银首饰与其他产品组成成套消费品销售的，应按销售额全额征收消费税。

### 第2题（单选题）
**题目**：下列关于卷烟消费税计税价格的核定，说法错误的是？
- A. 生产企业实际销售价格高于核定计税价格的，按实际销售价格申报纳税
- B. 未经国家税务总局核定计税价格的新牌号、新规格卷烟，生产企业应按卷烟调拨价格申报纳税
- C. 国家税务总局按照卷烟批发环节销售价格加上卷烟批发环节批发毛利核定计税价格 ✗（应为"扣除"）
- D. 卷烟消费税最低计税价格核定范围为卷烟生产企业在生产环节销售的所有牌号、规格的卷烟

**正确答案**：C

### 第3题（单选题）
**题目**：下列应税消费品中，适用从价定率方法计征消费税的是？
- A. 啤酒（从量定额）
- B. 电子烟（从价定率）✓
- C. 汽油（从量定额）
- D. 白酒（复合计税）

**解析**：从量定额计征：啤酒、黄酒、成品油；复合计税：卷烟和白酒；从价定率：电子烟等。

### 第4题（单选题·计算题）
**题目**：甲卷烟生产企业2025年3月出厂销售A牌卷烟500标准箱，出厂价格每标准条60元，批发环节价格每标准条115元，批发毛利率31%。应缴纳消费税？
- A. 562.95万元 ✓
- B. 364.58万元
- C. 277.5万元
- D. 121.61万元

**计算过程**：
1. 核定计税价格 = 115 × (1-31%) = 79.35元/条（≥70元，甲类卷烟，税率56%）
2. 从价税 = 500×250×79.35×56% = 555.45万元
3. 从量税 = 500×250×200×0.003 = 7.5万元
4. 合计 = 562.95万元

**题目**：纳税人用于下列情形的自产应税消费品，应以同类应税消费品的最高销售价格作为计税依据的有？

### 第6题（多选题）
**题目**：下列关于消费税计税依据的表述中，正确的是？
- A. 礼花厂通过自设非独立核算门市部销售焰火，按移送价格征收（错误，应按门市部对外销售额）
- B. 采用翻新改制方式销售的金银首饰，按实际收取不含税价款确定计税依据 ✓

**正确答案**：BD

## 知识点补充

1. **成套消费品销售**：金银首饰与其他产品组成成套销售，按销售额全额征税
2. **卷烟核定计税价格**：批发价格 × (1 - 批发毛利率)，不是"加上"
3. **计税方法分类**：从量定额（啤酒、黄酒、成品油）、从价定率（电子烟）、复合计税（卷烟、白酒）
4. **最高销售价格适用场景**：换取生产资料/消费资料、投资入股、抵偿债务（换抵投）
5. **非独立核算门市部**：按门市部对外销售额征税，不是移送价格
6. **品牌使用费**：属于价外费用，应并入销售额
