## 知识点补充

1. **消费税征税环节**：生产/进口/委托加工为主，特殊：卷烟批发加征、金银首饰零售征收、超豪华小汽车零售加征
2. **纳税人vs代收代缴义务人**：委托加工中委托方是纳税人，受托方是代收代缴义务人
3. **自产自用**：用于连续生产应税消费品不征税，用于其他方面（馈赠、管理部门、在建工程等）视同销售征税
4. **高档化妆品标准**：≥10元/毫升（克）或15元/片（张）
5. **航空煤油**：暂缓征收消费税
6. **卡丁车**：不属于小汽车税目
7. **税率形式**：比例税率（多数）、定额税率（黄酒、啤酒、成品油）、复合税率（卷烟、白酒）
