## 第一次做题错题分析

### 失分原因
1. **多选题点击丢失**：第21题4个选项点击全部报错，但还是跳到了第22题，导致第21题0分
2. **未参考知识库**：部分题目基于记忆作答，知识点掌握不牢固
3. **时间管理**：用时42分钟，时间到了自动提交，没有检查时间

### 经验教训
1. 多选题每个选项点击后必须确认选中成功，再点击下一个选项
2. 多选题点击间隔 ≥ 1000ms，避免点击丢失
3. 做题前必须参考知识库，禁止自己猜答案
4. 交卷前通过答题卡快速检查所有题是否都有选中状态

## 易错题与记忆要点

### 1. 税收立法权划分（易错题！）
- 国务院的权力需要"经全国人大及其常委会授权或为执行法律的规定"
- 国家税务主管部门和省级人民政府的权力都需要"经国务院授权"，不是经全国人大授权
- 看到"国务院有...权力"要警惕，通常需要授权
- 看到"国家税务主管部门有...权力"或"省级人民政府有...权力"要警惕，通常需要"经国务院授权"

### 2. 国际重复征税（易混淆！）
- 前提条件：纳税人所得或收益的国际化和各国所得税制的普遍化
- 根本原因：各国行使的税收管辖权的重叠
- 避免重复征税的方法：免税法和抵免法

### 3. 已立法 vs 未立法
- 已立法14个税种：企业所得税、个人所得税、车船税、环境保护税、烟叶税、船舶吨税、车辆购置税、耕地占用税、资源税、契税、城市维护建设税、印花税、关税、增值税
- 未立法4个税种（记忆口诀："消房两土"）：消费税、房产税、城镇土地使用税、土地增值税

### 4. 税收收入划分
- 中央固定收入（记忆口诀："消车关船"）：消费税、车辆购置税、关税、船舶吨税
- 地方固定收入（记忆口诀："房地车耕土环契烟"）：房产税、城镇土地使用税、车船税、耕地占用税、土地增值税、环境保护税、契税、烟叶税
- 共享收入（记忆口诀："增企个资城印"）：增值税、企业所得税、个人所得税、资源税、城市维护建设税、印花税
