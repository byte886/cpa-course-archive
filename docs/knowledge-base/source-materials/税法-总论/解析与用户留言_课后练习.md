## 试卷1：税法概念（3题）

### 第1题（单选题）

**题目**：以下关于税收和税法的表述中，正确的是（ ）。
- A. 税法属于义务性法规
- B. 税收的分配依据是基于生产要素进行的分配
- C. 税收是国家取得财政收入的唯一来源
- D. 税收分配是以纳税人为主体进行的分配

**我的答案**：A
**正确答案**：A
**答题用时**：1分24秒
**全站正确率**：74%

**官方解析**：
本题考查税收与税法的概念。选项A，税法属于义务性法规，以规定纳税人的义务为主。选项B，税收分配是国家凭借政治权力，以法律的形式进行的分配，而一般分配则是基于生产要素进行的分配。选项C，税收是国家取得财政收入的一种重要工具，不是唯一来源。国家取得财政收入的手段多种多样，除了征税，还可以发行货币、发行国债、收费、罚没等，税收只是大部分国家取得财政收入的主要形式。选项D，税收分配是以国家为主体进行的分配。所以，正确选项为A。

**用户留言**：
1. **缪张飞**（7赞）：生产要素分配是市场主导的初次分配，基于要素贡献。例如：企业支付工资基于劳动要素、企业为股东分红基于资本要素。税收分配是政府主导的再分配，基于公共职能和社会公平目标，依据法律和政策。
2. **月落琳**（0赞）：税收分配是以国家为主体进行的分配，而非纳税人。毕竟是由国家来分配税收的；政治权力是国家征税的依据，而非生产要素，生产要素是一般分配的依据
3. **Eaaaach**（0赞）：税收分配是国家凭借政治权力，以法律的形式进行的分配。【是以国家为主体的分配，是政府主导的再分配】...而生产要素分配是基于生产要素进行的分配。【是市场主导的初次分配】...
4. **CPA1223**（0赞）：税法是义务性法规，以规定纳税人的义务为主

**考点标签**：税法概念

## 试卷6：税务权利与义务（3题）

### 第1题（多选题）

**题目**：以下属于税务机关与纳税人的权利义务的表述中，正确的有（ ）。
- A. 税务机关应该为纳税人、扣缴义务人的税收违法行为保密
- B. 税务机关应当广泛宣传税收法律、行政法规，普及纳税知识，无偿地为纳税人提供纳税咨询服务
- C. 纳税人依法享有申请减税、免税、退税的权利
- D. 为了精简机构、节约征管成本，税务机关负责征收、管理、稽查，行政复议人员可以交叉兼任

**正确答案**：B,C
**全站正确率**：68%

**官方解析**：
本题考查税务行政主体、纳税人的权利与义务。选项A，纳税人、扣缴义务人有权要求税务机关为纳税人、扣缴义务人的情况保密，是指对纳税人、扣缴义务人的商业秘密和个人隐私保密。纳税人、扣缴义务人的税收违法行为不属于保密范围。选项D，税务机关负责征收、管理、稽查，行政复议人员的职责应当明确，并相互分离、相互制约。所以，正确选项为BC。

**用户留言**：
