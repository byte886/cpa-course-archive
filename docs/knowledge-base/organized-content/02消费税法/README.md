## 章节概述

消费税法是CPA税法考试的重点章节，主要介绍消费税的纳税义务人、征税范围、税目与税率、计税依据、应纳税额的计算、征收管理等内容。

### 重点内容

1. **纳税义务人与征税范围**：消费税的性质（中央税）、与增值税的关系、5个征税环节（生产、委托加工、进口、批发、零售）
2. **税目与税率**：15个税目、比例税率与定额税率、特殊税率（卷烟复合计税、超豪华小汽车加征）
3. **计税依据**：从价计征、从量计征、复合计征、包装物押金的处理、视同销售的计税价格
4. **应纳税额计算**：生产销售环节、委托加工环节、进口环节、已纳消费税扣除
5. **征收管理**：纳税义务发生时间、纳税期限、纳税地点
