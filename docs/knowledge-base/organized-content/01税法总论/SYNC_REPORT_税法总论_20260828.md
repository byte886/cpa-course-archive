## 六、问题与解决

### 6.1 遇到的问题

| 问题 | 解决方法 | 状态 |
|------|---------|------|
| 飞书知识库页面被误删 | 通过回收站（Trash）恢复页面 | ✅ 已解决 |
| 恢复的页面是旧版本，不包含最新内容 | 使用lark-cli API更新页面内容 | ✅ 已解决 |
| Playwright直接编辑飞书页面困难 | 使用lark-cli docs +update命令，通过stdin传递Markdown内容 | ✅ 已解决 |
| lark-cli --content不接受绝对路径 | 使用stdin方式传递内容（cat file \| lark-cli ... --content -） | ✅ 已解决 |

### 6.2 经验总结

1. **优先使用API更新**：lark-cli docs +update比Playwright手动编辑更高效、更可靠
2. **使用stdin传递内容**：避免文件路径问题，适合大文件更新
3. **Markdown格式支持好**：飞书文档支持标准Markdown语法，包括标题、表格、列表、引用等
4. **双重验证很重要**：同步前验证本地，同步后验证飞书，确保内容一致
5. **回收站是安全网**：误删页面可以通过回收站恢复，但恢复的是旧版本，需要重新同步最新内容
