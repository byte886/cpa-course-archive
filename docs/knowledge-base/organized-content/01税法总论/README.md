## 章节概述

税法总论是CPA税法考试的基础章节，主要介绍税法的基本概念、基本原则、税法要素、税收立法与税法体系、税收执法、税务权利与义务、国际税收关系等内容。

### 重点内容

1. **税法概念**：税收的定义与特征、税收法律关系的构成
2. **税法原则**：基本原则（4个）和适用原则（6个）的区分与应用
3. **税法要素**：征税对象、税率的类型、差别比例税率的分类
4. **税收立法与税法体系**：税收立法机关层级、已立法税种清单、税收实体法vs程序法
5. **税收执法**：税收收入划分（中央固定、地方固定、共享）、税收执法权
6. **税务权利与义务**：纳税人的权利、涉税专业服务机构的业务范围
7. **国际税收关系**：国际重复征税、国际税收协定
