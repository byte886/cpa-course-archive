# 高顿做题验证交互优化指南

## 目的
通过多轮实践观察交互模式，总结经验，优化流程，提高效率和正确率。

## 交互规律（已验证）

### 1. 单选题：选择后自动跳题
- **规律**：单选题选择选项后，页面自动跳到下一题
- **操作**：不需要手动点击"下一题"按钮
- **注意**：选择后立即进入下一题，需确认当前题号

### 2. 多选题：选择后不自动跳题
- **规律**：多选题选择选项后，页面不自动跳转
- **操作**：需要手动点击"下一题"按钮
- **注意**：多选题需要选择多个选项，全部选择完后再点击"下一题"

### 3. 灰色背景 = 鼠标悬停状态
- **规律**：选项有灰色背景只是鼠标悬停状态，不是预选
- **正确判断**：只有蓝色圆圈（单选）或蓝色方框（多选）才代表已选择
- **注意**：不要被灰色背景误导，确认蓝色标记

## 已发现的交互问题

### 1. 多选题快速连续点击只保存最后一个
- **现象**：多选题快速连续点击多个选项后，可能只保存了最后一个选择
- **案例**：税收执法第7题，选择了 A、B、C，但系统只保存了 C
- **原因**：选项点击事件需要时间处理，快速连续点击可能导致前面的选择未保存
- **影响**：多选题漏选，导致失分
- **解决方法**：
  - 每个选项选择后等待 1000ms
  - 全部选择完后截图确认所有选项都有蓝色标记
  - 确认后再点击"下一题"

### 2. 选择未保存（历史问题，已通过规律理解解决）
- **现象**：之前误以为选择后页面自动跳转导致选择未保存
- **实际原因**：单选题选择后自动跳题是正常交互，选择已保存
- **案例**：税法要素第2题，之前误以为选了D但系统记录了B，实际可能是交互操作问题
- **当前状态**：通过理解交互规律，此问题已基本解决

## 优化方案

### 方案0：知识库查询强制要求（核心规范，必须严格执行）

**⚠️ 每道题必须先查询知识库，再选择答案。禁止凭记忆答题。**

#### 单选题查询流程
1. 阅读题目，识别考点（如"税收立法"、"税收执法"等）
2. 在知识库文档中搜索相关知识点
3. 记录查询结果（正确答案是什么）
4. 根据查询结果选择答案
5. 选择后再次确认答案与知识库一致

#### 多选题查询流程（更严格）
1. 阅读题目，识别考点
2. 在知识库文档中搜索相关知识点
3. **逐个选项验证**：A选项是否正确？B选项是否正确？C选项是否正确？D选项是否正确？
4. 记录每个选项的验证结果
5. 根据验证结果选择所有正确选项
6. 选择后再次确认每个选项与知识库一致

#### 知识库查询位置
- 知识拆解：`docs/knowledge-base/organized-content/<章节名>/知识拆解.md`
- 考试指导：`docs/knowledge-base/organized-content/<章节名>/考试指导.md`
- 通用方法：`docs/knowledge-base/organized-content/做题思路解析.md`

#### 时效性注意
- 对于有时间敏感性的知识点（如"增值税是否立法"），必须特别注意知识库中的时效性说明
- 知识库中明确标注"2024年12月25日通过立法，2026年1月1日施行"的，必须按最新状态答题

### 方案1：单选题操作流程
1. 阅读题目，识别考点
2. **查询知识库**，记录正确答案（方案0）
3. 获取当前题目的选项ref（snapshot + grep）
4. 点击正确选项
5. **单题完成检查**：确认选项有蓝色圆圈标记（已选择）
6. 页面自动跳到下一题（不需要手动点"下一题"）
7. 确认当前题号是下一题（避免跳题）

### 方案2：多选题操作流程
1. 阅读题目，识别考点
2. **查询知识库**，逐个选项验证，记录所有正确答案（方案0）
3. 获取当前题目的选项ref（snapshot + grep）
4. 点击第一个正确选项，等待 1000ms
5. **单选项检查**：确认该选项有蓝色方框标记
6. 点击第二个正确选项，等待 1000ms
7. **单选项检查**：确认该选项有蓝色方框标记
8. （如有更多选项，重复上述步骤）
9. **整题完成检查**：截图确认所有正确选项都有蓝色标记
10. 点击"下一题"按钮
11. 确认当前题号是下一题（避免跳题）

### 方案3：补题流程（发现未做题时）

**⚠️ 发现未做题后，必须完成所有未做题才能交卷，中途不交卷。**

#### 步骤1：发现未做题
- 交卷时系统提示"你还有X题未做"
- 或打开答题卡发现有白色未做题

#### 步骤2：记录所有未做题编号
- 打开答题卡，逐个检查题目状态
- 记录所有未做题的编号（如"第1、3、5、7题未做"）
- **必须记录完整，不能遗漏**

#### 步骤3：依次通过答题卡补做所有未做题
- 通过答题卡点击第一个未做题的编号
- 按单选题或多选题操作流程完成该题
- **单题完成检查**：确认选项有蓝色标记
- 通过答题卡点击下一个未做题的编号
- 重复上述步骤，直到所有未做题都完成
- **中途不交卷**，必须完成所有未做题

#### 步骤4：补题完成后再次检查
- 打开答题卡，确认所有题目都已作答（无白色未做题）
- 确认无误后点击"交卷"

#### 补题注意事项
- **不要从头依次做**：只通过答题卡点击未做题的编号，避免把做过的题又反向选择了（取消选择）
- **不要中途交卷**：必须完成所有未做题才能交卷
- **每道题都要检查**：补做的每道题都要确认选项有蓝色标记

### 方案4：交卷前检查
1. 打开答题卡，确认所有题目都已作答（无白色未做题）
2. 如有未做题，点击题号跳转补做
3. 确认无误后点击"交卷"

## 新增优化点（2026-08-28）

### 1. 题目内容获取优化
- **问题**：有时候grep不到题目内容，需要用更大的范围或不同的关键词
- **解决方案**：固定使用"paragraph [ref=e" + 更大的范围（-A 20），或者使用"多选题"/"单选题"作为锚点
- **验证**：税法原则课后练习中使用此方法，所有题目都成功获取

### 2. 交卷确认框ref每次不同
- **问题**：交卷确认框的ref每次都不同，不能硬编码
- **解决方案**：每次点击交卷后，重新获取确认框的ref，再点击确认交卷
- **验证**：所有试卷都使用此方法，交卷成功

### 3. 单选题命令拆分标准
- **问题**：单选题一批超过3题时，命令容易超时被移到后台
- **解决方案**：单选题每批最多3题，避免超时
- **验证**：分章真题测第三次做题使用此方法，没有出现超时
