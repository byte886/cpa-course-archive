# 高顿题库做题流程与方法论

> 本文档记录高顿教育平台（glivepro.gaodun.com）题库做题的完整流程、交互优化经验和知识库使用方法。每次做题后应根据新发现迭代更新本文档。

## 一、做题前准备

### 1.1 环境准备
- **浏览器**：Chrome（通过 Playwright CLI 自动化控制）
- **Playwright Session**：`ga`（已登录高顿账号，保持登录态）
- **知识库**：飞书知识库「CPA考试知识库」，包含各章节知识本身和考试指导

### 1.2 进入做题页面
1. 打开课程表页面：`https://glivepro.gaodun.com/course/42660/class-schedule`
2. 找到对应试卷标题（如"【全面精讲-课后练习】税法-税法概念"），点击标题文字进入
3. 新标签页打开做题界面，切换到新标签页开始做题

### 1.3 试卷类型识别
- **课后练习**：每节课后1-8题，题目较少
- **分章真题测**：每章约20-25题，题目较多
- **模考卷**：每套约48题，综合性强
- **总考试**：课程结束后的综合考试

## 二、单选题做题流程

### 2.1 操作步骤
1. **截图当前题目**：`npx playwright cli -s=ga screenshot --filename=q{N}.png`
2. **读取题目内容**：用 Read 工具查看截图，识别题干和选项
3. **查询知识库**：根据题目考点，在知识库中查找对应知识点
4. **确定答案**：基于知识库内容和税法知识，确定正确选项
5. **获取选项 ref**：`npx playwright cli -s=ga snapshot --depth=8 | grep "generic \[ref=e[0-9]+\]: [A-D]$"`
6. **点击正确选项**：`npx playwright cli -s=ga click e{ref}`
7. **等待自动跳题**：单选题选择后会自动跳到下一题，等待2秒
8. **截图下一题**：重复步骤1-7

### 2.2 单选题特点
- 选择后**自动跳题**，无需手动点击"下一题"
- 选项 ref 格式：`e{数字}`，每题的 ref 不同
- 灰色背景的选项是之前做过的标记（可能是正确答案或已选答案）

## 三、多选题做题流程（关键优化点）

### 3.1 操作步骤
1. **截图当前题目**：同单选题
2. **读取题目内容**：识别题干、选项和题型（多选题）
3. **查询知识库**：确定所有正确选项
4. **获取选项 ref**：同单选题
5. **逐个点击正确选项**：
   ```bash
   npx playwright cli -s=ga click e{ref1}
   npx playwright cli -s=ga wait-for 1000  # 关键：每个选项间隔1秒
   npx playwright cli -s=ga click e{ref2}
   npx playwright cli -s=ga wait-for 1000
   # ... 更多选项
   ```
6. **验证选择状态**：截图确认所有正确选项都有蓝色圆圈标记
7. **点击"下一题"按钮**：多选题**不会自动跳题**，必须手动点击
   ```bash
   npx playwright cli -s=ga snapshot --depth=8 | grep "下一题"
   npx playwright cli -s=ga click e{下一题按钮ref}
   ```
8. **等待页面加载**：等待2秒后截图下一题

### 3.2 多选题关键优化（血泪教训）

#### 问题：多选题选项未保存
- **现象**：多选题只选了第一个选项，后续选项未保存，导致得分低
- **原因**：
  1. 点击选项间隔太短（<500ms），前端状态未更新
  2. 误以为多选题会自动跳题，未点击"下一题"
  3. 点击"下一题"后立即截图，页面还在加载

#### 解决方案（已验证有效）
1. **每个选项点击后等待1000ms**：确保前端状态更新
2. **多选题必须手动点击"下一题"**：不会自动跳题
3. **点击"下一题"后等待2000ms**：确保页面完全加载
4. **验证选择状态**：点击选项后截图确认蓝色圆圈出现

#### 验证结果
- 优化前：税法原则7题得4分（57%），税法要素7题得6分（85%）
- 优化后：税收执法8题得8分（100%），税务权利与义务3题得3分（100%），国际税收关系3题得3分（100%）

## 四、知识库使用方法

### 4.1 知识库结构
- **知识本身**：按章节整理的税法知识点，用于理解和记忆
- **考试指导**：考点分析、做题技巧、易错点总结

### 4.2 查询策略
1. **关键词匹配**：根据题目中的关键词（如"征税对象"、"税收管辖权"）在知识库中搜索
2. **章节定位**：根据试卷名称确定章节，直接查阅对应章节的知识内容
3. **交叉验证**：如果知识库内容不完整，结合通用税法知识判断

### 4.3 知识库补充
- 做题过程中发现知识库缺失的知识点，应记录下来
- 试卷完成后，根据错题和新发现补充知识库
- 补充内容应区分"知识本身"和"考试指导"

## 五、交卷与成绩验证

### 5.1 交卷流程
1. 所有题目完成后，点击右上角"交卷"按钮
2. 确认交卷（可能有弹窗确认）
3. 等待成绩页面加载

### 5.2 成绩验证
1. **截图成绩页面**：记录得分、正确率、用时
2. **查看答题卡**：确认哪些题正确、哪些题错误
3. **查看错题解析**：点击"全部解析"查看错题原因
4. **记录成绩**：更新到交互优化指南的成绩统计表

### 5.3 成绩统计格式

| 税法概念 | 3 | 3/3 | 100% | 0 | 0 | |

## 六、常见问题与解决方案

### 6.1 Playwright CLI 问题
- **Session 断开**：重新运行 `npx playwright cli -s=ga open <url>` 恢复
- **ref 变化**：每次页面刷新后 ref 会变化，必须重新获取
- **点击无反应**：可能是元素未加载完成，增加等待时间

### 6.2 题目识别问题
- **截图不清晰**：增加 `thumbnail_size=large` 读取截图
- **选项文字太长**：用 snapshot 获取完整文字内容
- **题型判断错误**：注意题目上方的"单选题"/"多选题"标签

### 6.3 知识库查询问题
- **找不到对应知识点**：可能知识库尚未覆盖，结合通用知识判断并记录补充
- **知识点冲突**：以最新教材和官方规定为准

## 七、做题效率优化

### 7.1 批量处理策略
- 单选题可以快速连续处理（每题约30秒）
- 多选题需要谨慎操作（每题约1-2分钟）
- 大试卷（20题以上）建议分批次完成，避免疲劳导致错误

### 7.2 自动化脚本
- 对于重复性操作（如获取选项 ref、点击选项），可以编写脚本批量执行
- 但题目理解和答案判断必须由 AI 完成，不能纯自动化

### 7.3 时间估算
- 单选题：每题约30秒（含截图、读题、查询、点击）
- 多选题：每题约1-2分钟（含验证和手动下一题）
- 10题试卷：约10-15分钟
- 20题试卷：约20-30分钟
- 48题模考卷：约60-90分钟
