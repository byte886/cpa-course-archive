# 做题流程与交互规范

本文档记录高顿题库（GlivePro）做题自动化的流程规范、交互注意事项和踩坑经验。

## 一、页面管理原则

### 1.1 操作前检查

每次开始做题前，必须先检查当前浏览器的标签页数量和状态：

```bash
playwright cli -s=<session> snapshot 2>&1 | grep -A 20 "Open tabs"
```

### 1.2 页面识别

- **当前工作页**：URL 中 `resState/0` 表示未完成试卷，`resState/1` 表示已完成试卷
- **多余页面**：已完成的试卷页面、其他课程页面、飞书文档页面等
- **重复页面**：同一试卷可能同时存在未完成（resState/0）和已完成（resState/1）两个标签页

### 1.3 处理原则

1. 优先在 `resState/0`（未完成）的页面上操作
2. 多余页面**可以自动关闭**（Playwright CLI 支持标签页管理）
3. 如果页面异常（ref 失效、点击无响应），先刷新页面或重新打开试卷链接，不要在异常页面上反复尝试

### 1.4 自动管理标签页

Playwright CLI 提供完整的标签页管理命令：

```bash
# 列出所有标签页（含索引、标题、URL）
playwright cli -s=<session> tab-list

# 切换到指定索引的标签页
playwright cli -s=<session> tab-select <index>

# 关闭指定索引的标签页
playwright cli -s=<session> tab-close <index>

# 新建标签页
playwright cli -s=<session> tab-new [url]
```

**自动清理流程**：
1. 做题前执行 `tab-list`，识别当前工作页（`resState/0` 的未完成试卷）
2. 从后往前关闭多余页面（避免索引变化导致关错）
3. 只保留当前工作页，如需参考文档可额外保留1个飞书文档页
4. 关闭后再次执行 `tab-list` 确认

**注意**：关闭标签页时从最大索引开始，因为关闭前面的页面会导致后续索引变化。

## 二、补题流程（核心规范）

### 2.1 原则

**当系统提示有未做题时，必须通过答题卡单独挑选未做题，禁止从头依次重做。**

原因：从头依次重做会导致已做题被反向点击（取消选择），且浪费时间。

### 2.2 正确流程

1. 打开答题卡（点击页面右上角"答题卡"按钮）
2. 逐题点击题号，检查该题是否已做（通过选项是否有选中状态判断）
3. 只对未做题进行作答
4. 已做题跳过，不要点击选项

### 2.3 未做题识别方法

目前答题卡上没有直接的"已做/未做"颜色标识，需要逐题检查：

- 点击题号跳转到该题
- 观察选项是否有选中状态（active class）
- 如果无选中状态，说明未做，进行作答
- 如果有选中状态，说明已做，直接跳下一题

> **注意**：active 状态的 class 名可能因页面刷新而变化，不要依赖固定 class 名，应通过视觉或 DOM 结构判断。

## 三、做题交互注意事项

### 3.0 做题前准备：参考知识库（核心规范）

**做题前必须先参考知识库中的相关考点内容，禁止自己猜答案。**

**流程**：
1. 进入试卷后，先浏览所有题目，识别考点标签
2. 对于每个考点，先查阅知识库中对应的知识拆解和考试指导文档
3. 基于知识库内容作答，不要凭印象或猜测
4. 对于知识库中没有的知识点，做完题后要补充到知识库中
5. **新知识点补充原则（重要）**：做题过程中发现的任何新知识点（无论是考试指导相关的，还是非指导考试的），都必须补充到**知识拆解**文档中。非指导考试的知识点（如知识背景、扩展应用、跨学科联系、实际案例等）同样需要补充，不能因为"不直接考"就忽略。知识拆解的目标是构建完整的知识体系，不仅服务于考试，也服务于知识应用、搜索和AI问答。

**效率优化：批量查阅知识库**
- 进入试卷后，先快速浏览所有题目（通过答题卡逐题查看题干），识别所有考点
- 批量查阅知识库中对应的考点内容，一次性获取所有需要的知识点
- 避免每做一道题就搜索一次知识库，减少重复搜索时间

**知识库参考流程分级规则**：
- **L1 严格参考（新题目/首次做/记忆模糊）**：必须逐题查阅知识库，基于知识库内容作答，禁止自己猜
- **L2 快速确认（已做过1-2次且正确率≥80%）**：快速浏览题干，确认答案与知识库一致，如有疑问立即查阅知识库
- **L3 直接作答（已做过3次以上且连续100%正确）**：可直接作答，但交卷前必须通过答题卡检查所有题的选择状态
- **注意**：分级规则仅适用于同一套题的重复练习，新试卷必须从L1开始

**知识库位置**：
- 知识拆解：`docs/knowledge-base/organized-content/XX课程名/知识拆解.md`
- 考试指导：`docs/knowledge-base/organized-content/XX课程名/考试指导.md`
- 做题记录：`docs/knowledge-base/source-materials/XX课程名/做题记录_*.md`

**反例**：
1. 2026-08-28 错题加练中，关于"税收立法权"的多选题，知识库中已有"地方立法权需要经国务院授权"的记录，但未参考知识库，自己猜了全选，导致答错。
2. 2026-08-28 税法（种）要素课后练习第6题，关于"哪些税种有具体税目"的多选题，知识库中考试指导文档已明确记录"增值税、消费税、资源税、印花税、个人所得税有具体税目，企业所得税没有"，并有记忆口诀"增消资印个"有税目，但未参考知识库，凭记忆认为增值税没有具体税目，导致漏选A选项，答错。

**教训**：知识库中已有正确知识点但未查阅导致做错，这是流程执行不到位的问题，不是知识库不完善的问题。必须严格遵循"做题前参考知识库"的规范，不能凭记忆作答。

**强制执行检查清单（每道题作答前必须确认）**：

每道题作答前，必须按以下清单逐项确认，未确认不得作答：

1. **已识别考点**：确认这道题考查的是什么知识点（如税法原则、税法要素、税收立法等）
2. **已查阅知识库**：确认已查阅知识库中对应的知识拆解和考试指导文档
   - 知识拆解：`docs/knowledge-base/organized-content/XX课程名/知识拆解.md`
   - 考试指导：`docs/knowledge-base/organized-content/XX课程名/考试指导.md`
3. **已找到相关内容**：确认在知识库中找到了与这道题相关的知识点
4. **基于知识库作答**：确认答案是基于知识库内容，而不是凭记忆或猜测
5. **易错题特别检查**：如果是易错题（全站正确率<50%），必须逐字核对知识库中的表述

**执行方式**：
- 可以使用`grep`命令快速搜索知识库中的相关内容：`grep -r "关键词" docs/knowledge-base/organized-content/`
- 对于多选题，必须确认每个选项都在知识库中有对应的依据
- 对于记忆模糊的题目，必须查阅知识库，不能凭印象作答

**违反检查清单的后果**：
- 如果发现作答时没有执行检查清单，必须立即停止当前操作
- 重新查阅知识库
- 重新作答
- 将本次教训补充到对应文档中

### 3.0.1 遇到错误时的验证流程

当做题过程中发现以下情况时，必须重新做题来验证和优化流程：

1. **知识点错误**：答错题目，且知识库中已有相关记录但未参考 → 说明流程执行不到位，需要重新做题验证"做题前参考知识库"的流程
2. **知识库不完整**：答错题目，且知识库中没有相关知识点 → 先补充知识库，然后重新做题验证补充后的知识库是否有效
3. **交互问题**：点击丢失、答题卡遮挡、自动跳题异常等 → 优化交互流程后，重新做题验证
4. **流程优化**：发现新的效率提升方法或避坑经验 → 更新文档后，重新做题验证优化效果

**验证标准**：
- 重新做题的正确率应高于或等于之前的正确率
- 交互流程应更顺畅，无点击丢失或异常
- 做题时间应更短或相当

### 3.1 单选题

- 选择选项后**会自动跳题**，无需手动点击"下一题"
- 如果选择后没有自动跳题，可能是：
  - 答题卡还打开着，遮挡了选项 → 先关闭答题卡（点击页面空白处）
  - 页面加载异常 → 刷新页面
- **命令拆分标准**：单选题每批最多3题，避免命令超时被移到后台。如果一批超过3题，应拆分成多个命令

### 3.1.1 交卷前检查流程（强制）

所有题目完成后，交卷前必须执行以下检查：
1. 打开答题卡，逐题检查是否都有选择状态
2. 对于多选题，确认所有正确选项都已选中
3. 如果发现未做题，通过答题卡单独挑选未做题作答（禁止从头依次重做）
4. 确认所有题都做完后，再点击"交卷"→"确认交卷"

### 3.2 多选题

- 选择选项后**不会自动跳题**，必须手动点击"下一题"
- 多个选项之间点击间隔建议 ≥ 1000ms，避免点击丢失（经测试1000ms足够，无需1500ms）
- **点击后验证选择状态**：每个选项点击后，通过snapshot检查该选项是否有选中状态（如蓝色圆圈或active class），确认成功后再点击下一个选项
- 最后一题（多选题）选择完成后，手动点击"交卷"
- **命令拆分**：多选题操作避免在一个Bash命令中包含太多sleep和点击，防止命令超时被移到后台。可以将4个选项的点击拆分成2个命令（每2个选项一个命令）

### 3.3 答题卡操作

- **打开答题卡后必须先关闭再做题**，否则答题卡会遮挡选项，导致点击失败
- 关闭方法：点击页面空白区域（非答题卡区域）
- 通过答题卡跳题后，答题卡会自动关闭，但有时不会，需手动确认

### 3.4 交卷确认

- 点击"交卷"后，如果有未做题，会弹出确认框"你还有X题未做，确定交卷吗？"
- 此时应点击"继续做题"，返回补题，不要点击"确认交卷"
- 确认所有题都做完后，再点击"交卷"→"确认交卷"

### 3.5 时间到处理

- 考试时间到了会弹出对话框"已经到考试结束时间了哦，要立即交卷吗？"，有"立即交卷"按钮
- **直接点击"立即交卷"提交**，不要继续做题（时间到后继续做题没有意义）
- 提交后查看成绩，记录正确率和失分原因

### 3.6 错题处理流程

当做题出现错题时，必须按照以下流程处理：

1. **记录错题**：将错题的题干、选项、我的答案、正确答案、解析记录到做题记录文档中
2. **分析错因**：
   - 是知识库没有相关知识点？→ 补充知识库
   - 是知识库有记录但未参考？→ 强化"做题前参考知识库"的流程
   - 是交互问题（点击丢失等）？→ 优化交互流程
3. **补充知识库**：将错题涉及的知识点补充到知识拆解和考试指导文档中
4. **做错题加练**：在成绩页面点击"错题加练"按钮，重新做错题，验证是否掌握
5. **验证效果**：错题加练的正确率应达到100%，否则重复上述流程

**错题记录位置**：`docs/knowledge-base/source-materials/XX课程名/做题记录_*.md`

## 四、本次踩坑记录（2026-08-27）

### 4.1 问题1：答题卡遮挡导致点击失败

**现象**：点击选项时报错 `TimeoutError`，但 ref 是正确的。

**原因**：答题卡还打开着，悬浮在选项上方，导致点击被拦截。

**解决**：点击选项前，先点击页面空白处关闭答题卡。

### 4.2 问题2：从头重做导致已做题被取消

**现象**：系统提示13题未做，从第1题开始依次重做，结果做完后还是提示有未做题。

**原因**：从头依次重做时，已做题被再次点击（反向选择），导致取消选择。

**解决**：通过答题卡逐题检查，只做未做题。

### 4.3 问题3：active 状态检测不可靠

**现象**：用 `grep -c "sub-tiku__question-active"` 检测选中状态，结果为0，但实际已选中。

**原因**：class 名可能因页面刷新而变化，或 active 状态用其他方式表示。

**解决**：不依赖固定 class 名检测，通过是否自动跳题判断单选题是否选中成功。

### 4.4 问题4：多选题点击丢失

**现象**：多选题连续点击多个选项时，部分点击报错 `TimeoutError`，但还是跳到了下一题，导致该题部分选项未选中。

**原因**：多选题多个选项之间点击间隔太短（<1000ms），页面还没响应完就发起下一次点击，导致点击丢失。

**解决**：多选题多个选项之间点击间隔必须 ≥ 1000ms，点击完成后手动点击"下一题"前确认所有选项都已选中。

### 4.5 问题5：时间到后继续做题

**现象**：考试时间到了弹出"立即交卷"对话框，但还在继续做题，导致时间浪费。

**解决**：时间到了直接点击"立即交卷"提交，不要继续做题。

## 五、考试记录与经验总结

### 5.1 2026-08-28 第一次做题（税法总论-分章真题测）

**基本信息**：
- 考试名称：【26-精讲】税法-分章真题测-税法总论
- 题目数量：22题（13单选 + 9多选）
- 总用时：41分59秒
- 得分：12/22分
- 正确率：约54.5%
- 全站平均分：15.77分

**失分原因分析**：
1. **多选题点击丢失**：第21题4个选项点击全部报错，但还是跳到了第22题，导致第21题0分
2. **部分题可能答错**：知识点掌握不牢固，需要结合知识库复习
3. **时间管理**：用时42分钟，时间到了自动提交，没有检查时间

**经验教训**：
1. 多选题每个选项点击后必须确认选中成功（观察是否有选中状态），再点击下一个选项
2. 多选题点击间隔 ≥ 1000ms，避免点击丢失
3. 交卷前通过答题卡快速检查所有题是否都有选中状态
4. 时间到了直接提交，不要继续做题

### 5.4 2026-08-28 第四次做题（税法（种）要素课后练习）

**基本信息**：
- 考试名称：【全面精讲-课后练习】税法-税法（种）要素
- 题目数量：7题（3单选 + 4多选）
- 总用时：约2分42秒
- 得分：6/7分
- 正确率：85%
- 全站平均分：4.56分
- 击败同类考生：40%

**错题分析**：
- 第6题（多选题）：下列税种中，规定了具体税目的有（ ）
  - 我的答案：B、D（消费税、个人所得税）
  - 正确答案：A、B、D（增值税、消费税、个人所得税）
  - 错误原因：误认为增值税没有具体税目。实际上增值税有具体税目（销售货物、提供加工修理修配劳务、销售服务、无形资产、不动产等）
  - 解析：目前我国税法体系中，对增值税、消费税、资源税、印花税和个人所得税等，规定了具体的税目，但对企业所得税没有设置具体税目

**交互流程优化点（重要）**：
1. **读取成绩时必须区分"得分"和"最高得分"**：
   - "得分"是本次考试的实际得分（如6分）
   - "最高得分"是历史最高分（如7分），不是本次得分
   - 之前错误地把"最高得分7分"当成了"本次得分"，导致成绩记录错误
   - **正确做法**：同时读取"得分"、"答对题数"、"正确率"三个字段，交叉验证
2. **交卷后必须查看"错题解析"**：
   - 考试报告页面有"错题解析"按钮，可以快速定位错题
   - 不能只看总分，必须确认哪道题答错了
   - 错题解析包含：题目、我的答案、正确答案、解析、用户留言
3. **知识库知识点补充**：
   - 增值税有具体税目（销售货物、提供加工修理修配劳务、销售服务、无形资产、不动产等）
   - 企业所得税没有设置具体税目
   - 需要将这个知识点补充到知识库的"税法（种）要素"章节

**成绩读取规范（强制执行）**：
交卷后读取成绩时，必须按以下顺序读取并验证：
1. 读取"得分"字段（本次实际得分）
2. 读取"答对题数"字段
3. 读取"正确率"字段
4. 交叉验证：得分 = 答对题数（每题1分），正确率 = 答对题数 / 总题数
5. 点击"错题解析"，确认哪道题答错了
6. 记录错题详情（题目、我的答案、正确答案、解析）

**禁止行为**：
- ❌ 只读取"最高得分"就当成是本次得分
- ❌ 不查看错题解析就记录成绩
- ❌ 不交叉验证得分、答对题数、正确率三个字段

## 六、效率优化建议

### 6.1 做题效率优化

1. **批量查阅知识库**：进入试卷后先快速浏览所有题目，识别所有考点，批量查阅知识库，避免每道题都搜索一次
2. **先做单选后做多选**：单选题自动跳题效率高（每题约3-5秒），先完成所有单选题，再集中处理多选题（每题约5-8秒）
3. **多选题点击间隔1000ms**：经测试1000ms足够，无需1500ms，可节省约1分钟
4. **命令拆分**：多选题操作避免在一个Bash命令中包含太多sleep和点击，防止超时被移到后台。可将4个选项拆分成2个命令
5. **交卷前检查**：交卷前通过答题卡快速扫一遍，确认所有题都有选中状态
6. **页面保持干净**：做题前关闭多余标签页，避免内存占用和ref混乱

### 6.2 知识库检索效率优化

1. **按考点快速定位**：知识库按课程名组织，知识拆解和考试指导分开，可快速定位
2. **使用grep批量搜索**：使用`grep -r "关键词" docs/knowledge-base/`批量搜索相关内容
3. **高频考点标记**：在考试指导文档中标记高频考点和易错题，方便快速查阅

### 6.3 交卷确认自动化

1. 点击"交卷"后，自动检测是否弹出确认框
2. 如果有未做题，点击"继续做题"返回补题
3. 如果所有题都做完，点击"确认交卷"提交
4. 提交后自动获取成绩并记录
