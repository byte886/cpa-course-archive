# 知识库父节点目录清单模板

> **文档类型**：Template（模板骨架）
> **更新频率**：模板变更时
> **维护者**：AI自动维护
> **读者**：AI代理

> 本模板用于创建课程父节点和章节父节点的目录清单页面。
> 详细规范见 `knowledge-base-organization.md` 第1.0.1节。

## 模板说明

### 适用范围
- 课程节点（如【26考季】VIPCPA系列-税法）
- 章节节点（如01税法总论、02增值税法）

### 必须包含
1. **基本信息块**：课程/章节名称、主讲老师、整理来源、适用范围、更新时间
2. **子节点目录清单**：子文档的完整URL链接，每个链接附带简要说明
3. **章节概述**：简要介绍主要内容和学习目标
4. **重点内容**：列出核心知识点（3-7条）
5. **学习建议**：给出学习顺序和方法建议

### 不包含
- 正文知识点内容（父页面只是目录，不承载知识内容）
- 重复的章节框架（子文档中已有）
- 文档维护说明（流程相关文档记录，不放在知识库中）

## 使用说明

### 创建步骤
1. 复制对应模板（章节父节点或课程父节点）
2. 替换占位符（章节名称、课程名称、老师姓名、node_token等）
3. 填写章节概述、重点内容、学习建议
4. 使用lark-cli更新飞书知识库页面
5. 验证链接是否有效，内容是否完整

### 更新步骤
1. 子文档内容变更时，更新父节点的重点内容和学习建议
2. 新增子文档时，更新父节点的目录清单
3. 子文档拆解时，更新父节点的目录清单，列出所有子文档
4. 使用lark-cli更新飞书知识库页面
5. 验证链接是否有效

### 注意事项
- 链接必须使用完整的飞书URL（https://zcnjheoajxng.feishu.cn/wiki/[node_token]），不使用相对路径
- 重点内容控制在3-7条，过多会失去重点
- 章节概述简洁明了，2-3句话即可
- 学习建议通用化，不需要针对每个章节重复相同内容
