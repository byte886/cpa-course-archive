# 做题记录模板

> **文档类型**：Template（模板）
> **更新频率**：做题流程优化时
> **维护者**：AI自动维护
> **读者**：AI代理

> 本文档定义做题记录的标准格式和数据采集规范，确保后续汇总和知识库迭代时有统一、准确的数据源。
> **重要原则**：做题不用强求全部做对，做完就可以。记录时以**最终正确答案**为准，避免把中间做错的选择当答案。如果用户请求可以再做一遍。

---

## 一、做题记录文件命名规范

**格式**：`做题记录_<试卷名称简写>.md`

**示例**：
- `做题记录_消费税纳税人税目与税率.md`
- `做题记录_消费税的计税依据.md`
- `做题记录_分章真题测_税法总论.md`

**存放位置**：`knowledge-base/source-materials/<章节名>/`

---

## 二、做题记录标准格式

### 2.1 头部信息（必填）

```markdown
# 做题记录：<试卷完整名称>

**试卷名称**：<试卷完整名称，如【26-精讲】税法-知识点测试-消费税的计税依据>
**题目数量**：<N>题
**完成时间**：<YYYY-MM-DD>
**正确率**：<百分比>（<做对题数>/<总题数>）
**做题轮次**：<第1轮/第2轮/重做>
```

**说明**：
- 正确率如实记录，不用强求100%
- 如果是重做，标注"第2轮"或"重做"

### 2.2 题目与解析（每题必填）

```markdown
### 第<N>题（<题型>）<作答结果标记>

**题目**：<完整题目内容>

- A. <选项A内容> <是否正确标记>
- B. <选项B内容> <是否正确标记>
- C. <选项C内容> <是否正确标记>
- D. <选项D内容> <是否正确标记>

**正确答案**：<最终正确答案，如A / ABD / 562.95万元>

**解析**：<官方解析或AI解析，说明为什么选这个答案>

**计算过程**（仅计算题）：
1. <计算步骤1>
2. <计算步骤2>
3. <计算步骤3>
4. <合计结果>

**记忆口诀**（如有）：<记忆口诀内容>

**用户留言精华**（如有高赞留言）：
> <用户留言内容>
```

#### 选项标记规范（重要！避免把错题当答案）

| 标记 | 含义 | 使用场景 |
|------|------|---------|
| `✓` | 该选项是正确答案 | 最终正确的选项，不管AI是否选对 |
| `✗` | 该选项是错误答案 | 明确错误的选项，可标注错误原因 |
| 无标记 | 干扰项，不选 | 普通干扰项，不需要特别标注 |
| `（AI选错）` | AI在做题时选错了这个选项 | 记录AI的错误，用于后续分析，但**正确答案以官方为准** |

**重要原则**：
- `✓`标记的是**最终正确答案**，不是AI选的答案
- 如果AI选错了，在选项后标注`（AI选错，正确答案是X）`，但`✓`仍然标在正确选项上
- 避免把AI中间做错的选择当正确答案

#### 题型分类

- 单选题
- 多选题
- 判断题
- 计算题（单选题·计算题）
- 综合题
- 不定项选择题

#### 作答结果标记（题目标题后）

| 标记 | 含义 |
|------|------|
| `✓` | AI做对了 |
| `✗` | AI做错了 |
| `（未作答）` | AI没有作答（如交互问题跳过） |
| 无标记 | 不需要特别标注 |

### 2.3 知识点补充（文档末尾，必填）

```markdown
## 知识点补充

1. **<知识点1>**：<知识点说明>
2. **<知识点2>**：<知识点说明>
3. **<易错点1>**：<易错点说明>
4. **<记忆口诀1>**：<记忆口诀内容>
5. **<考点分析>**：<考点分析内容>
```

**说明**：
- 从所有题目中提炼的关键知识点、易错点、记忆口诀
- 用于后续汇总到考试指导文档
- 按重要性排序，最重要的放前面

## 三、数据采集清单（做题时必须采集的数据）

### 3.1 每道题必须采集

| 数据项 | 是否必填 | 说明 |
|--------|---------|------|
| 题目完整内容 | ✅ 必填 | 完整的题目描述，不能省略 |
| 所有选项（A/B/C/D） | ✅ 必填 | 完整的选项内容，不能省略 |
| 最终正确答案 | ✅ 必填 | 以官方答案为准，不管AI是否选对 |
| 官方解析 | ✅ 必填 | 平台提供的解析，如果没有则AI解析 |
| AI作答结果 | ✅ 必填 | AI选了什么，是否做对 |
| 题型 | ✅ 必填 | 单选/多选/计算/判断等 |

### 3.2 每道题按需采集

| 数据项 | 是否必填 | 说明 |
|--------|---------|------|
| 计算过程 | 计算题必填 | 详细的计算步骤 |
| 记忆口诀 | 如有则采集 | 平台或用户提供的记忆口诀 |
| 用户留言精华 | 如有高赞则采集 | 高赞用户留言，用引用块标注 |
| 考点标签 | 如有则采集 | 平台标注的考点标签 |
| 举一反三题目 | 如有则采集 | 平台提供的类似题目 |

### 3.3 试卷级别必须采集

| 数据项 | 是否必填 | 说明 |
|--------|---------|------|
| 试卷完整名称 | ✅ 必填 | 平台显示的完整试卷名称 |
| 题目数量 | ✅ 必填 | 总题数 |
| 完成时间 | ✅ 必填 | 做题完成日期 |
| 正确率 | ✅ 必填 | 做对题数/总题数 |
| 知识点补充 | ✅ 必填 | 从题目中提炼的知识点汇总 |

## 四、数据采集注意事项

### 4.1 避免把错题当答案

1. **正确答案以官方为准**：不管AI选对还是选错，`✓`永远标在官方正确答案上
2. **记录AI的错误**：如果AI选错了，在选项后标注`（AI选错）`，但不要把AI的选择当正确答案
3. **多选题特别注意**：多选题的正确答案可能是多个，要全部标`✓`，不能只标AI选的那几个
4. **未作答的题目**：如果因为交互问题没有作答，也要记录正确答案，标注`（未作答）`

### 4.2 数据完整性

1. **题目和选项要完整**：不能省略题目或选项内容，确保后续可以独立理解
2. **解析要详细**：官方解析要完整记录，如果没有官方解析，AI解析要说明理由
3. **计算题要有过程**：不能只记录答案，要有详细的计算步骤
4. **用户留言要筛选**：只记录高赞、有价值的用户留言，不要记录无意义的灌水

### 4.3 做题轮次

1. **第一轮做题**：如实记录正确率，不用强求100%
2. **如果用户请求重做**：可以做第二轮，标注"第2轮"或"重做"
3. **重做时**：可以只记录第一轮做错的题目，或者全部重做，根据用户需求
4. **多轮记录**：如果有多轮，每轮单独一个文件，或者在同一文件中按轮次分节

## 五、做题记录的用途

1. **知识库迭代**：知识点补充、易错点、记忆口诀用于更新考试指导文档
2. **知识库验证**：用做题结果验证知识库的准确性，发现遗漏的知识点
3. **做题经验总结**：分析AI做错的原因，优化做题流程和交互
4. **用户学习参考**：用户可以查看做题记录，了解考点和易错点
