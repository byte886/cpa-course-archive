# 角色定义目录

## 用途

本目录存放本项目外围多角色任务的角色配置文件，用于在豆包工作伙伴中配置对应的AI角色。

**重要说明**：
- 本目录仅存放**本项目需要的4种角色定义**，不存放通用的豆包多角色定制方法论
- 通用的操作指南、踩坑记录、技能配置方法等内容存放在**飞书知识库**中：「AI」→「飞书」→「豆包多角色定制」
- 后续遇到同类问题，直接查询飞书知识库，不要在本仓库内新增通用方法论文档

## 4种角色

| 角色 | 目录 | 状态 | 职责 |
|------|------|------|------|
| 项目架构师 | `project-architect/` | ✅ 已配置 | 基于软件工程化的项目设计，目录和文件命名规范，任务规划与管理，协调各角色 |
| 开发工程师 | `developer/` | ⏳ 待配置 | 代码开发、脚本编写、技术实现、自动化工具开发 |
| 产品经理 | `product-manager/` | ⏳ 待配置 | 需求梳理、PRD编写、产品测试、业务知识整理 |
| 测试工程师 | `test-engineer/` | ⏳ 待配置 | 质量验证、测试用例、知识库质量检查、流程验证 |

## 每个角色包含的文件

每个角色目录下包含以下4个配置文件：

| 文件 | 用途 |
|------|------|
| `AGENTS.md` | 角色工作空间主配置（启动顺序、技能列表、执行门禁等） |
| `IDENTITY.md` | 角色身份定义（角色名称、定位、核心能力） |
| `SOUL.md` | 角色灵魂/价值观 |
| `USER.md` | 用户画像 |

## 配置方法

角色配置的详细操作方法、踩坑记录、AGENTS.md编辑技巧等，请参考飞书知识库：
- 「AI」→「飞书」→「豆包多角色定制」→「豆包多角色定制 - 操作指南与踩坑记录」

**关键技术点**：AGENTS.md编辑器使用CodeMirror 6，长内容粘贴需使用ClipboardEvent直接触发paste事件，绕过系统剪贴板限制。
