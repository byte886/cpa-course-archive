## 三、P2 内容采集

### 3.1 视频下载流程（已验证）

1. Playwright 附加 Chrome → 打开课程表页
2. 遍历每个"看回放"按钮（跳过"开班典礼"）
3. 点击回放 → 新标签页打开播放器
4. 注入 Worker hook → 切换 1080P → 截获 FHD m3u8 URL + AES 密钥
5. 下载全部分片（20 并发）→ AES-128-CBC 解密 → 合并 .ts
6. ffmpeg 压缩为 H.265 MP4（iTerm 窗口显示进度）
7. ffprobe 验证：时长完整、编码正确、moov atom 存在
8. 关闭播放器标签页 → 下一个视频

### 3.2 文档下载流程

1. 在课程表页提取每个场次下的"下载"链接
2. 下载 PDF 到对应场次的 `docs/` 目录
3. 记录文件名、大小、类型（讲义/课件/试卷）

### 3.3 预计工作量

| 课程 | 视频数（跳过开班典礼） | 单视频时长 | 总时长 | 预计总大小 |
|------|----------------------|-----------|--------|-----------|
| 税法 | ~38 个 | 2-3.5 小时 | ~100 小时 | ~10-15 GB |
