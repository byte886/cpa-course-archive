# 文档同步清单

> 本文档记录项目中所有需要同步更新的文档，以及同步时机和更新内容。
> 每次完成阶段性任务后，按此清单检查并同步相关文档。

---

## 一、同步时机

| 时机 | 需要同步的文档类别 |
|------|-------------------|
| **开始新任务前** | 任务状态、测试计划 |
| **完成单个讲座流程后** | 任务状态、课程索引、做题记录（如有） |
| **完成所有试卷后** | 知识库内容、验证报告、方法论 |
| **发现问题并解决后** | 工作流、开发文档、方法论 |
| **项目结构调整后** | README、工作流、目录结构说明 |
| **大阶段完成后** | 全部文档检查一遍 |

## 九、同步检查流程

每次完成阶段性任务后，按以下流程检查：

1. **任务状态**：TASK_STATUS.md 和飞书表格是否更新？
2. **测试计划**：TEST_PLAN_*.md 中的完成状态是否更新？
3. **做题产出**：做题记录、用户笔记、验证报告是否生成？
4. **知识库内容**：知识拆解、考试指导是否需要补充？
5. **方法论**：是否有新的经验需要总结到方法论文档？
6. **工作流**：流程是否有变化需要更新？
7. **README**：项目结构、存储分工是否有变化？

---

## 十、注意事项

- **本地文档为主**：所有文档先在本地更新，再同步到飞书
- **飞书表格为辅**：飞书多维表格用于分享和可视化，与本地TASK_STATUS.md保持一致
- **一次性整合**：知识库内容（知识拆解、考试指导）建议所有试卷做完后一次性整合，避免反复修改
- **问题驱动更新**：发现任何问题时，立即评估是否需要更新相关文档
