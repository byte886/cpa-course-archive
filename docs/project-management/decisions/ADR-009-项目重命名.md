# ADR-009: 项目重命名 cpa-course-archive → gaodun-course-knowledge-base

> **文档类型**：Active（决策记录）
> **更新频率**：决策变更时
> **维护者**：AI自动维护
> **读者**：AI代理+人类

## 状态

已采纳（2026-08-29）

## 背景

原项目名称存在两个核心问题：

1. **范围太窄**：
   - 仓库名 `cpa-course-archive` 只提到CPA
   - 但项目还包括其他课程（如会计基础必修）
   - 本地目录名 `gaodun_downloads` 只强调"下载"，但项目还包括压缩、转写、知识库、做题验证等

2. **定位不准**：
   - "archive"（归档）只是备份的意思
   - 但项目的核心是生成知识库、做题验证、持续迭代
   - README标题"高顿 CPA 课程智能归档项目"同样存在这两个问题

3. **名称不统一**：
   - GitHub仓库：cpa-course-archive
   - 本地目录：gaodun_downloads
   - README标题：高顿 CPA 课程智能归档项目
   - 百度网盘应用：CPA课程归档
   - 多个名称不一致，容易混淆

## 决策

### 1. 新项目名称

| 位置 | 旧名称 | 新名称 |
|------|--------|--------|
| **GitHub仓库** | `cpa-course-archive` | `gaodun-course-knowledge-base` |
| **本地目录** | `gaodun_downloads` | `gaodun-course-knowledge-base` |
| **README标题** | 高顿 CPA 课程智能归档项目 | 高顿课程知识库系统 |
| **中文名称** | CPA课程归档 | 高顿课程知识库系统 |
| **百度网盘应用** | CPA课程归档 | **保持不变**（修改需要重新创建应用，成本高） |

### 2. 选择 `gaodun-course-knowledge-base` 的理由

1. **范围准确**：包括所有高顿课程（CPA、会计基础必修等），不局限于CPA
2. **定位准确**：核心目标是知识库系统，而不仅仅是归档
3. **功能完整**：隐含了视频下载、文档备份、内容解析、知识库生成、做题验证等完整流程
4. **可扩展**：未来可以加入其他教育平台的课程，只需要改前缀

### 3. 同步更新的内容

1. GitHub仓库重命名（通过 `gh repo rename` 命令）
2. 本地目录重命名
3. Git远程地址 origin URL 更新
4. 所有文档中的标题和引用更新（README、CONTRIBUTING、TASK_STATUS、ADR-005、DIRECTORY_STRUCTURE、PROJECT_PLAN）
5. CHANGELOG.md中添加重命名记录
6. 记录到本ADR

## 后果

### 正面
- 项目名称范围准确，包括所有高顿课程
- 项目名称定位准确，核心目标是知识库系统
- 所有文档中的标题和引用已同步更新，名称统一
- Git远程地址已更新，推送正常
- 未来新增其他课程时，不需要再次重命名

### 负面
- 旧的GitHub链接（`https://github.com/byte886/cpa-course-archive`）会自动重定向到新地址，但外部引用可能需要手动更新
- 百度网盘应用名称仍为"CPA课程归档"，与新项目名称不一致（但修改成本高，保持不变）
- 本地目录路径变化，其他脚本或配置中如果有硬编码路径需要更新（已检查，没有发现）

### 后续
- 定期检查项目名称是否仍然准确（如果项目范围扩大到其他教育平台，可能需要再次重命名）
- 百度网盘应用名称如果未来需要修改，可以在百度网盘开放平台重新创建应用
- 所有新增文档必须使用新项目名称，禁止使用旧名称
