# 目录与文件命名规范

> **文档类型**：Governance（治理规范）
> **更新频率**：命名规范变更时
> **维护者**：AI自动维护
> **读者**：AI代理（所有操作必须遵守）

> 本规范适用于高顿CPA课程项目中所有本地目录、百度网盘目录、以及知识库节点的命名。
> 所有自动化脚本和手动操作必须严格遵守本规范。

---

## 一、顶层目录结构

```
高顿/                           ← 教育公司名（顶级）
└── CPA/                        ← 专业/考试类别
    ├── 课程库/                  ← 走完整流程（有知识库）
    │   └── {课程目录}/
    │       └── {章节目录}/
    └── 待整理/                  ← 未走完整流程（暂无知识库）
        └── {课程目录}/
            └── {章节目录}/
```

---

## 二、课程目录命名

### 格式

```
【{考季}考季】VIPCPA系列-{科目}（{老师}老师）
```

### 示例

- `【26考季】VIPCPA系列-税法（蔡俊峻老师）`
- `【26考季】VIPCPA系列-会计（罗翔老师）`
- `【26考季】VIPCPA系列-审计（{老师}老师）`

### 规则

1. 考季用两位数字，如 `26` 代表2026年
2. 必须包含 `VIPCPA系列-` 前缀
3. 科目名用标准简称：税法、会计、审计、财管、经济法、战略
4. 老师名后必须加 `老师`，用中文括号 `（）`
5. **禁止**出现 `基础必修`、`全面精讲` 等班次描述在课程目录层（班次在章节层体现）

---

## 三、章节目录命名

### 格式

```
{两位序号}_{章节完整名称}
```

### 示例

- `00_开班典礼&规划方法`
- `01_税法全面精讲01-税法总论`
- `02_税法全面精讲02-增值税法（一）`
- `03_冲刺模考-机考`

### 规则

1. 序号用两位数字，从 `00` 开始（开班典礼为00）
2. 序号与名称之间用下划线 `_` 分隔
3. 章节名称必须完整，包含班次信息（如 `全面精讲01`）
4. 名称中的括号用中文括号 `（）`
5. **禁止**重复序号（如 `01_税法全面精讲01-` 中的 `01` 是班次编号，不是章节序号，两者含义不同但可以共存）

---

## 四、章节内文件命名

### 固定文件名（所有章节统一）

| 文件 | 命名 | 说明 |
|------|------|------|
| 视频 | `video.mp4` | 压缩后的视频 |
| 音频转写 | `transcript.md` | 转写文字稿（面向使用者） |
| 转写原始数据 | `transcript.json` | FunASR原始输出（技术过程文件，不上传网盘） |
| 知识拆解 | `知识拆解.md` | 面向知识应用和搜索 |
| 考试指导 | `考试指导.md` | 面向考试（记忆口诀、易错点、答题技巧） |
| 验证报告 | `VERIFICATION.md` | 本章节的质量验证报告（如有） |

### docs/ 目录（原始文档）

| 文档类型 | 命名格式 | 示例 |
|----------|----------|------|
| 讲义 | `讲义_{名称}.pdf` | `讲义_开班典礼+税法基本功.pdf` |
| 课件 | `课件_{名称}.pdf` | `课件_0开班典礼.pdf` |
| 其他 | `{类型}_{名称}.{ext}` | `题目_分章真题.pdf` |

### docs_text/ 目录（OCR文字稿）

| 文档类型 | 命名格式 | 示例 |
|----------|----------|------|
| 讲义OCR | `讲义_{名称}_OCR.md` | `讲义_开班典礼+税法基本功_OCR.md` |
| 课件OCR | `课件_{名称}_OCR.md` | `课件_0开班典礼_OCR.md` |

**规则：**
- 所有OCR文字稿必须加 `_OCR` 后缀
- 文件名与 docs/ 下的原始文件对应（仅扩展名和后缀不同）

## 五、知识库节点命名

### 课程节点

```
{科目}（{老师}老师）
```

示例：`税法（蔡俊峻老师）`

### 章节节点

```
{两位序号}{章节名称}
```

示例：`00开班典礼&规划方法`、`01税法总论`

### 子节点（章节下）

每个章节节点下固定两个子节点：
- `知识拆解`
- `考试指导`

### 父节点内容要求

- 课程节点和章节节点（父节点）必须包含子节点的链接目录
- 当子节点内容更新时，父节点的概述内容需同步更新
- 父节点是否需要生成正文内容，由AI根据节点性质决定（课程节点通常需要课程概述，章节节点通常需要章节概述+子节点链接）

## 六、网盘与本地一致性规则

1. 百度网盘目录结构必须与本地目录结构完全一致
2. 网盘路径前缀：`/apps/CPA课程归档/高顿/`
3. **不上传网盘的文件**（技术过程文件）：
   - `transcript.json`（转写原始数据）
   - `VERIFICATION.md`（验证报告，仅本地保留）
   - 临时文件、日志文件
4. **上传网盘的文件**（面向使用者）：
   - `video.mp4`
   - `transcript.md`
   - `知识拆解.md`
   - `考试指导.md`
   - `docs/` 下所有原始文档
   - `docs_text/` 下所有OCR文字稿

---

## 七、命名检查清单

每次创建新目录或文件后，必须检查：

- [ ] 课程目录是否符合 `【{考季}考季】VIPCPA系列-{科目}（{老师}老师）` 格式
- [ ] 章节目录是否为 `{两位序号}_{名称}` 格式
- [ ] 视频是否命名为 `video.mp4`
- [ ] 知识库文件是否为 `知识拆解.md` / `考试指导.md`（非英文）
- [ ] docs_text/ 下文件是否都有 `_OCR` 后缀
- [ ] 网盘目录结构是否与本地一致
- [ ] 技术过程文件（transcript.json等）是否未上传网盘

## 八、目录命名校验与一致性检查（自动化）

### 8.1 创建目录前的命名验证

创建任何讲座目录前，必须验证目录名符合以下规范：

```
格式：两位序号_课程类型-章节名
示例：01_税法全面精讲01-税法总论
例外：00_开班典礼&规划方法（开班典礼用00序号，用&分隔）
```

**验证规则：**
- 必须以两位数字开头（00-99）
- 必须包含`-`分隔符（开班典礼除外，用`&`）
- `-`后必须包含中文章节名
- 禁止创建只有序号和课程类型、缺少章节名的目录（如`01_税法全面精讲01`）

### 8.2 定期检查本地和网盘目录结构一致性

**执行时机：**
- 每次完成一个讲座的完整流程后
- 每次批量处理多个讲座前
- 发现目录结构异常时

**检查内容：**
1. 本地和网盘的目录数量是否一致
2. 目录命名是否符合规范
3. 是否存在空目录（0个文件）
4. 是否存在不完整命名的目录

**检查命令：**

```bash
# 检查本地目录命名规范
bash scripts/check_directory_structure.sh local

# 检查网盘目录命名规范
bash scripts/check_directory_structure.sh remote

# 同时检查本地和网盘
bash scripts/check_directory_structure.sh both
```

### 8.3 清理不完整命名的空目录

发现不完整命名的空目录时，必须立即清理：

```bash
# 自动检测并删除空的不完整命名目录
bash scripts/check_directory_structure.sh clean
```

**清理原则：**
- 只删除文件数为0的空目录
- 不删除有内容的目录（即使命名不完整，需要先迁移内容）
- 清理后记录到任务报告

### 8.4 本地与网盘目录镜像原则

- 本地目录创建后，必须同步创建到网盘（或在上传时自动创建）
- 本地目录删除或重命名后，必须同步到网盘
- 每次上传完成后，必须验证网盘目录结构与本地一致
